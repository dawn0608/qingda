# 助手设定自动草稿与整份生效

## 号主资料

智能助手左侧分为上方「助手设定」和下方「号主资料」，扣除20px间距后各占一半高度，整体与右侧回复范围上下边框对齐。标题固定，长正文在各自区域显示滚动条；源码模式同样在内部滚动。窄屏沿用上下排列，两个编辑区仍等高。

资料用于填写允许向好友和群聊公开的称呼、公司、职位、业务介绍等事实，默认留空、不从微信平台资料推断。复用相同Markdown编辑器、自动草稿及结束编辑生效时序，两块独立保存；切换账号、页面及退出登录时统一处理，失败保留内容。资料可清空，不关闭助手。

生效资料存于逐用户RLS隔离的`settings`，键为`owner_profile:<account_id>:<微信身份SHA256>`，草稿在同键追加`:draft`；不新增表或迁移。`GET/PUT /accounts/{id}/owner-profile-draft`以及`POST .../apply`、`POST .../resolve`复用原草稿请求与回执，必须带读取时的`owner_wxid`查询参数，服务端核对当前身份、核验终端和账号归属。长度上限50000字符，生效更新账号epoch并沿用原任务取消机制，相同版本回执不重复取消。

私聊和群聊共用当前身份的生效资料；以独立JSON对象作为事实数据装配入提示词，明确标识是否已配置，不追加到用户已有助手设定，不执行资料内指令。未知事实不编造、不代号主承诺；旧历史不能恢复已更正或删除的资料，不向搜索工具传送资料。群聊唤醒和回复范围不变。资料计入现有上下文预算，超限报错、不静默截断；追踪仅新增资料版本与哈希。

## 使用规则

- 微信身份首次核验成功时，从 `prompts/assistant_default.md` 按账号昵称填入默认设定；不依赖自动启用配置，不改变助手开关或回复范围。仅补齐无正文、无草稿且从未编辑或启用的账号；已有正文、草稿及主动清空的设定保留，后续昵称或模板变化不覆盖人工内容。
- 不显示格式工具栏、保存／放弃按钮或常驻保存条。沿用 Markdown 即时预览；Ctrl+/ 切换源码，原有格式、缩进和撤销快捷键继续可用。
- 停止输入约1.5秒自动保存草稿；中文组合输入期间暂停计时，组合结束后才保存完整文本。编辑期间线上助手继续使用原设定。
- 离开编辑区、切换账号或页面、退出登录时，先保存最新完整草稿再统一生效。Ctrl+S 可立即结束本轮编辑。只切换源码／预览不生效。
- 刷新或关闭页面优先保留草稿，不把浏览器退出视为可靠的生效时机。下次读取草稿不会自动生效；继续编辑并结束后才生效。
- 标题栏保持固定高度，保存／生效进度及紧凑「草稿待重试」入口位于原栏内。详细失败原因统一顶部短提示，正文继续保留；冲突在「处理冲突」操作菜单中提供「保留本页内容」「采用生效设定」，不自动选择、不覆盖另一处修改。
- 空草稿可保存；启用助手时不能使空设定生效。超过50000字符保留编辑内容并提示精简，不截断正文。

## 存储与时序

草稿复用 PostgreSQL `settings` 的逐用户RLS隔离，键为 `assistant_prompt_draft:<account_id>`，包含 Markdown、随机版本、原生效设定SHA256及更新时间；不新增数据库结构。所有入口验证认证用户、账号归属和CSRF，响应禁止缓存。

`GET/PUT /accounts/{id}/prompt-draft` 只读取／保存草稿；`POST .../apply` 校验版本和生效基线，在一个事务中更新原设定、现有任务状态及草稿回执。账号行锁解决首次草稿不存在时的竞争；生效沿用项目事务锁至账号锁的顺序，锁等待有界。相同内容不重复更新账号epoch，同版本重试不重复取消任务。`POST .../resolve` 仅在用户明确选择后重建基线，仍核对最新草稿版本及生效哈希。

前端串行保存和生效；回执仅推进已保存版本，不设置编辑器正文、光标或撤销栈。慢请求期间可持续输入，新内容随后保存；组词期间不提交中间稿，离开等待组词提交。重新进入编辑区会取消尚未开始的生效。账号／页面切换等待当前一轮完成，失败留在原处。

未确认保存的尾部同步备份到浏览器，按已认证用户、账号和标签页隔离；服务器已确认内容不重复备份。刷新可恢复同标签页尾稿。页面隐藏／退出尝试keepalive保存，超过浏览器单次keepalive预算仅保留本地尾稿；服务器保存失败且浏览器备份也不可用时才触发原生离开提示。网络结果不确定先做一次只读核对，已确认同版本生效才读取幂等回执，不盲目重复未知写入。

## 验证边界与入口

按改动影响执行隔离验证；本地或 CI 可运行静态检查、前端测试和构建。完整后端回归沿用专用 Linux/PostgreSQL 环境，见 `verification.md`。

- `backend/tests/test_prompt_drafts.py` 与原自动回复用例：真实隔离PostgreSQL，覆盖草稿不影响任务、原子生效、重复回执、两用户／账号隔离、HTTP认证／CSRF／上限、双进程竞争、崩溃回滚、有界等待及取消后的资源归还。
- `frontend/tests/prompt-draft-session.test.mjs`：服务器Node状态回归，覆盖延迟回执、组合输入、连续输入、一次生效、失败恢复、外部冲突和浏览器尾稿隔离。
- `evals/acceptance/prompt_editor_browser.py`：服务器独立Chromium与内存API夹具，覆盖原编辑规则及慢请求、刷新、错误、冲突、移动布局等51项；不替代真实接口生产验收。另以候选构建浏览器调用真实认证后端与隔离PostgreSQL，核验PUT草稿及POST生效的请求契约和时序。

生产另使用现有Chrome登录态及独立标签页，核对真实数据库草稿落盘期间生效哈希／epoch不变，结束编辑后整份生效一次，刷新恢复草稿、原设定恢复和所有源码／公开产物／Web／Worker版本。保留用户原标签页未保存内容。中文组合事件及iPhone触摸为自动模拟，不声称完成实体输入法或实体Safari体验验收。

## 编辑器规则

- Enter 新建段落，Shift+Enter 段内换行；段落中间分割、列表、引用、代码和表格继续由原生 Markdown 编辑器维护。
- 单个 `-` 不影响前一段；`- 内容` 创建列表，`---` 等有效分隔线在独立段落完成后渲染。已有 Markdown 中明确写出的 Setext 标题继续兼容。
- 即时预览按光标所在位置显示或隐藏标记；常用格式、列表、缩进、表格、分隔线与撤销重做通过 Markdown 或快捷键使用，界面不显示工具栏。
- Ctrl+/ 切换「即时预览」「Markdown 源码」；Ctrl+Alt+8/9 走同一切换入口。源码不显示分屏预览，查看模式不制造未保存修改、不累计结尾空行。
- 列表 Tab／Shift+Tab 可在条目内调整层级；代码与表格保留各自的 Tab 行为。
- Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做，Ctrl+S 结束本轮编辑并生效。切换前提交当前撤销记录、切换后立即记录基线，防止快速输入时漏掉第一步撤销。
- 中文组合输入期间不提交中间稿或切换模式；组合结束后同步完整内容。源码保存保留有意输入的末尾空行。

## 批量默认设定同步

`scripts/sync_assistant_prompts.py preview --snapshot <受保护目录>/before.json` 保存全部未归档账号的原设定、草稿、身份及候选正文；使用返回的哈希执行 `apply --snapshot <同一文件> --sha256 <哈希>`。逐用户事务核对快照后应用，重复执行返回原回执，不重复取消任务。账号名称、开关、人工暂停、回复范围和模型设置保持原值。与生效内容一致的干净草稿同步到新正文；真正未提交的草稿保留旧基线和原文，通过现有冲突交互处理。快照随本次发布材料保护至业务验收通过。
