# 验证码认证与用户范围

邮箱和手机号共用一个登录表单；验证码核验成功后登录，未注册联系方式自动创建用户，无密码、独立注册页或预置管理员。新用户昵称为“用户＋6位随机大写字母或数字”，可修改且可重复，不作为登录凭据。

每个用户可绑定一个邮箱和一个手机号。已登录用户更换时仅验证新联系方式，不重复验证当前身份；新联系方式不能属于另一用户。更换保留用户 ID、会话、微信账号及全部业务归属。

现有账号迁移须保留用户 ID、联系方式、有效会话及全部业务数据。密码认证已退役，升级与故障恢复均不得回退到旧密码认证版本。

会话、CSRF、来源检查和用户修订共同控制浏览器访问。验证码额度按目标与来源跨用途、跨进程累计，供应商调用前持久预占，失败或不确定结果不自动重试。SMTP 与阿里云配置由运行环境提供；真实收信与手机接收必须单独验收。

业务请求、回调、媒体及Worker使用服务端验证的用户范围，RLS缺省拒绝。新用户不会继承他人的Token、模型密钥或历史。

退出仅撤销当前浏览器会话，并通知同源页面重新读取身份；其他浏览器会话不受影响。身份变化时取消旧请求，不自动重新提交。
