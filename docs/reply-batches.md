# 回复调度与批次

自动回复使用持久发送队列。后台跨会话准备，同一会话互斥；同账号按答案就绪顺序串行发送，前次发送结束后至少间隔1秒。等待不占数据库连接，发送锁核对用户、账号与所有者。完成水位和租约支持进程重启。

批次按账号、会话和成员组织，原始消息及成员关联保持独立；文字、图片和语音按当前收集规则合并。生成中补充输入推进修订，旧结果作废，发送前重新检查。具体收集时长与唤醒见[回复策略](reply-strategy.md)。

发送前核对身份、在线、关系、账号／会话开关、人工接管、撤回、输入修订和平台时效。sending先落盘再调用平台；未知结果不自动重试。取消只释放本次拥有的资源，过期接管不越过未知副作用边界。

服务器回归覆盖跨进程领取、发送间隔、崩溃、取消和回执丢失。真实手机接收另行验收。
