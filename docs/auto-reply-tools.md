# 自动回复工具

文本与图片固定使用 DeepSeek 官方 deepseek-flash，保持非流式。思考模式固定关闭，联网搜索与网页抓取固定开启；历史用户设置、旧客户端和直接调用参数不能覆盖。最终正文仍须通过 finish_reply 校验。原生工具调用依次执行“模型请求 → 服务端校验 → 查询 → tool_call_id 回传 → 最终正文”；闲聊无需工具。时间、计算、天气、历史回查和媒体理解沿用原规则。

|工具|范围|
|---|---|
|和风天气|GeoAPI 确定城市或区县，重名澄清；实时天气、当地今天起最多10天逐日预报|
|DeepSeek Search|固定官方接口，最多5条摘要；query含语法最多128字符，支持site:、after:及before:|
|DeepSeek Fetch|用户给定或本任务搜索得到的公开网址，按需读取正文，最多20000字符并标记截断|
|当前时间|服务器时钟，默认 Asia/Shanghai，支持 IANA 时区；每轮生成和恢复注入可信 runtime_clock，普通相对日期无需额外取时；精确时刻或特殊时区使用时间工具，跨日重新核对|
|计算|AST 白名单和 Decimal，支持四则、括号、整数幂、后缀百分号；限制长度、节点、深度及数值范围，禁止 eval|

和风天气 API Host 与 API Key 由当前用户在系统设置中配置，成组存入受 RLS 隔离的 settings，Key 使用 Vault 加密。首次两项必填，后续留空保留密钥；不迁移旧凭据、无共享环境兜底。配置保存仅作格式校验，不发起查询。每次天气请求按当前用户异步读取一次完整快照，不缓存到共享对象；已开始的请求沿用本次快照，后续请求使用新配置，不取消普通回复。未配置返回 missing_weather_config。联网工具复用当前用户已加密保存的 `model_key`，异步按服务端验证的用户范围读取，不缓存到共享对象，不新增全局搜索密钥。Search/Fetch固定访问 `https://api.deepseek.com/v1/tools/search`、`https://api.deepseek.com/v1/tools/fetch`；密钥不进入模型输入、追踪、Git或发布包。天气仅访问配置的和风域名。网页正文和摘要均只作不可信资料，不能提升权限。

搜索前读取服务器时间，日期筛选通过query中的官方语法表达，旧freshness参数拒绝。Search使用count=5、need_content=false，映射官方date为published_at，未知日期保持空值，不虚构抓取时间。Fetch只接受本轮提问者网址或本任务成功搜索的来源，拒绝携带登录凭据、控制字符、本机或内网地址，调用前检查DNS所有地址。正文截断须明确说明缺口，空正文和超过2MiB的响应均返回错误；不自动执行网页脚本或加载网页资源。

web_tool_rate_limits保存全项目共享时间水位。Search/Fetch独立，每250ms最多启动一次，每次尝试都领取额度；短事务结束后才等待或联网，容量等待最多5秒且计入当前文本预算。崩溃最多保留250ms水位，无长期租约；取消不清除其他请求的记录。检查点和5分钟缓存仍隔离到本任务，工具指纹改变使旧检查点失效，历史证据保留。request_usage记录请求次数、HTTP成功次数、状态码及已知可计费结果次数；中断或格式无效时计费结果未知，不能当作免费。取消时已发生的调用仍通过执行事件记录。


文本生成累计预算为120秒；单次外部HTTP最多15秒，连接最多5秒，仅网络临时错误、408、429、5xx重试一次，受剩余总时间约束。权限、凭据、额度或格式错误不盲重试。模型轮数不设固定上限；截断、异常、超时不发送中间内容。天气或搜索失败以结构化错误回传模型，让最终正文说明暂时查不到并回答有依据的部分。

每轮模型、每次工具调用前后、等待期间及发送前检查规则、白名单、撤回、取消和人工接管。所有任务共用既有队列和间隔，平台结果不确定不重放。reply_generation_checkpoints保存当前任务的恢复状态。检查点保存续轮协议、工具结果及累计用量，输入指纹变化时失效；不复制初始媒体，不保存原始GeoAPI响应或坐标缓存。重启恢复仅针对仍有效任务，复用近期已完成的查询，当前时间重新读取。

trace_json 记录工具参数、结果、来源、查询时间、耗时与模型轮数；usage_json 汇总各模型轮次，调用证据保留在后台。搜索及天气来源默认不进入微信正文，用户明确询问或要求时再说明；天气供应商名称与官网链接保留在系统设置既有标题中。部署保留现有备份、候选核对和回滚流程，旧共用天气环境字段在配置备份后由发布入口清除，根 `.env` 保持 root:wechat-manager / 0640；回滚恢复旧源码、配置和依赖并保留最新业务数据库。

天气工具的 location_evidence 必填，接受本轮提问者逐字提供的地名或含地名原句。地点须与原文匹配，只允许去除一个末尾行政区划后缀辅助匹配，不猜别名或拼接历史地点；资料、引用及其他成员不提供地点授权。相关候选沿用本轮规则，网络及缓存读取前均重新校验。追踪的可选 location_evidence 字段保存 quote、matched_location、message_id。

天气失败附带 stage（validation、configuration、location_lookup、weather_query）和 request_sent，区分尚未请求与真实外部失败；参数错误先纠正，不能误报供应商故障。官方问题类型仅白名单解析，不回传原始错误正文；403不单凭状态码认定额度不足，明确凭据、权限及额度错误不重试。天气 request_usage 记录请求次数及HTTP状态，不代表实际计费次数。

验收分为服务器隔离回归、生产真实模型与工具、Dawn → WeMind 私聊完整链路。完整链路需要入站、工具记录、最终任务、平台受理及 Dawn 接收端证据，并包含查询期间人工接管。缺接收端证据时不得记为完成。固定案例见 `evals/acceptance/reply-tools.json` 及 `evals/acceptance/reply-web-tools.json`。真实评测命令须显式传入 `--user-id` 和 `--account-id`，按对应RLS范围读取模型配置和账号提示词；业务表只读，请求时钟属于运行元数据。
