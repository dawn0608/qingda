# 自动回复图片读取

## 来源与读取

图片像素由固定的deepseek-flash原生读取，真实引用与近期候选先冻结授权范围。

- 真实引用从同账号、同会话实际记录解析，核对终端、可见性、撤回及发生时间；支持其他成员及较早图片，不采信引用 XML 内嵌正文和任意地址。
- 群聊先图后问，仅选择当前提问者最近 120 秒最多 5 张图片，按时间排列。真实引用、明确当前图片优先，不混入旧候选；单图不扩大唤醒范围。私聊无需求单图仍询问意图。
- 输入标记 direct、quote、recent、原图和提问消息 ID、作者、图片状态。素材作者不替代回复对象，引用素材不进入 finish_reply 必处理输入集合。
- 状态区分 not_prepared、preparing、ready、download_failed、decode_failed、resource_expired、low_resolution、omitted_capacity；部分失败保留可用部分，不把信息不足说成获取失败。
- 官方下载优先 type=2，仅尝试原 XML 提供的高清和缩略规格；单图总预算 60 秒、每规格一次、瞬时故障全程最多额外重试一次。继续校验公网固定 IP、大小、实际解码、像素及 SHA256。
- 容量先移除历史图片和近期候选，必要图片超限留下明确省略标记，保留问题及引用文字。不根据模糊图片猜数字、活动规则或中奖率。

## 状态与恢复

reply_media_dependencies记录来源、输入修订、准备状态和素材指纹。图片来源、状态、帧哈希随完整上下文进入检查点指纹。下载前、缓存提交、生成完成和发送前复核权限、终端、人工接管、修订及撤回，外部等待不占数据库事务。

重新领取任务时重建依赖，避免撤回导致无限重排；取消仅释放本次准备标识，崩溃由取得全局 Worker 租约的进程接管。未知发送结果不重发。依赖纳入数据库备份，保留进行中会话所需消息；不补发历史任务、不自动清理聊天。
