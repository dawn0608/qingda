# 私聊回复

私聊按一轮输入统一回复：文字、引用、内置文字表情及语音收集2秒，普通静态图片收集5秒，主动等待最长30秒。重复回调不延长等待；MsgType=47贴图及动态图片不参与AI。生成中补充输入使旧结果失效，已完成素材可按指纹复用。

当前问题、历史、引用与手机人工发言各有明确角色；历史按真实问答关联取最近12轮、48条、12000 tokens，需要时在同一会话只读回查。历史旧要求不自动控制当前问题，用户最新更正优先。详见[回复策略](reply-strategy.md)和[上下文](conversation-context.md)。

人工发言暂停会话30分钟；提前恢复只处理新消息。素材失败保留原因并说明缺口，权限与撤回错误不降级发送。表情映射随发布编译成后端资源，真实Worker身份必须可读。
