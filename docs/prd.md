# 当前产品需求

管理台提供微信管理、智能助手和系统设置。用户通过邮箱或手机号验证码登录，未注册身份验证后自动创建独立账号；每个用户管理自己的微信Token、微信账号、模型密钥和会话。

微信管理展示当前账号身份、在线状态和最近成功查询时间。失败不推进成功时间。微信登录、退出和重登由官方平台操作，回调按AppID核实稳定身份，未知或冲突身份不得发送。

智能助手按账号管理总开关、助手设定和好友／群聊启用范围。设定自动保存草稿，结束编辑后整份原子生效；开关独立保存。回复范围每项提供只读聊天记录弹框，支持滚动加载全部已保存记录和关键词搜索；不提供人工发送或重试入口。好友和群聊分组展示，保留人工暂停及恢复入口。关闭回复、好友删除或退群不影响历史查看。

聊天记录展示微信会话中实际可见的聊天消息，包含文字、图片、语音、视频、文件、表情、位置、名片、链接、小程序、红包、转账及其他聊天类型；后台通知、拍一拍、入群及独立撤回提示等系统条目不展示。已撤回原消息保留原文、标记“已撤回”且可搜索。非文字消息只展示类型和已有文字、标题、文件名、时长或转写，不新增媒体读取或模型调用。历史范围为服务端实际接收保存的消息，不补采客户端此前历史。

系统设置保留微信接入和AI模型两个主面板。1280px及以上等宽双列、顶部对齐，窄屏纵向排列。Token仅当前认证用户可查看和修改，回调地址由服务器生成并只读展示；模型密钥按用户加密保存，配置响应禁止缓存。

DeepSeek固定使用deepseek-flash并只读展示，思考默认关闭、联网默认开启；文本累计预算120秒、默认输出16384 tokens。阿里百炼 `qwen-audio-3.1-asr-flash` 固定识别语音，支持多语种和方言；AI模型设置区分两个供应商，API Key 按用户独立配置并加密保存，文本与普通静态图片由DeepSeek原生处理，视频不下载、不解码、不参与AI。所有MsgType=47贴图及动态图片不下载、不解码、不参与AI，原始记录保留。

好友新消息或拍一拍按规则触发；群聊仅真实@、明确昵称呼叫、拍一拍、有效助手引用或本成员连续对话窗口触发。历史按真实问答与成员范围读取。手机自身发言触发人工接管；撤回、更正和范围变化使未提交结果失效。模型可明确静默，错误、截断与超时不算成功。

后台跨会话准备答案，同一会话互斥，同账号按答案就绪顺序串行发送，间隔至少1秒；不确定发送不自动重放。联系人与群关系独立后台核实，未知证据不授权发送。


所有业务历史、发送防重与ID高水位保留，不提供常规历史清空功能。现有界面布局、公网源与模型供应商保持有效配置；实际验收按[验证规则](verification.md)分别记录程序、模型、平台和接收端证据。
