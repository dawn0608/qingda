# 联系人与群关系同步

已核实且在线的账号由 Worker 自动同步通讯录，账号首次上线及恢复在线立即排队，正常周期为10分钟；离线账号每10分钟通过现有账号服务只读核对在线及身份，不依赖网页打开或收到消息。全量接口返回全部好友和已保存到微信通讯录的群；未保存的群沿用已有可信事件及关系核实，不自动保存群至微信通讯录，也不能枚举平台从未返回的群。

同步及对象核实成功后，批量补齐回复范围所需的会话配置。新增好友及群聊默认开启自动回复；新消息先建立的会话也使用相同默认值。目录同步本身不生成消息或任务，不重放历史消息；已有开关、人工暂停和历史保持不变。账号总开关、关系核实及群聊唤醒规则继续生效，系统对象、公众号及本人会话不自动开启。GET分页只读，目录中的未聊天对象也会自动显示。

好友展示资料使用 `/contacts/getDetailInfo`，每批最多20位；群展示资料使用 `/group/getChatroomInfo`，每次1群，只保存展示字段。失败保留已有资料，10分钟冷却后自动重试，成功更新备注、昵称和头像。页面隐藏暂停读取，返回恢复；同步状态收在原标题栏或空列表位置。

全量拉取每账号至少间隔10分钟；超时或成功占位只在90秒总预算内查询缓存，不重复发起全量请求。缺少清单、分页、接口失败和旧身份结果不得清空现有目录；缓存只补充展示，不能代替新全量关系证据。所有提交核对当前用户、账号、微信身份、终端操作和Worker租约。

当前微信身份的实时联系人变更、新私聊和群消息按账号、对象及身份进入持久核实队列，合并重复事件。回调本身不证明关系成立。

- 好友由 `/contacts/checkRelation` 精确匹配唯一wxid，仅整数relation=0确认；新增对象默认开启回复，已有选择保持不变。
- 群关系要求完整、非空、非缓存成员名单包含本人；新群不自动保存至微信通讯录。
- 未知、失败、限频、空名单和分页结果保留已有资料，持久退避重试；不据此误报退出。
- 明确删除、退群、被踢或解散后撤销当前关系与发送权限，聊天历史保留。重新发起的好友关系必须经过完整通讯录核实。

条目保存owner_wxid、saved_to_contacts和confirmed_at。旧身份响应、旧全量缓存不得覆盖较新确认；过期租约可接管，提交前核对身份快照和关系版本。失败指数退避至最多10分钟，限频至少60秒。

历史已知群按通讯录、会话和资料缓存去重核实，平台从未返回且没有回调的群无法枚举。已保存群数与全部有效群数分别维护。后台状态用于回复范围、身份保护和关系恢复，不提供独立消息管理页面。

服务器隔离回归覆盖发现、删除、恢复、重复事件、旧响应及重启；生产真实新增事件不足时，保留未验证结论，不将隔离重放当作实时验收。
