# 图片理解与语音识别

文本与普通静态图片统一使用当前用户密钥调用 DeepSeek 官方 `deepseek-flash`，型号由服务端固定，前端只读展示。思考模式固定关闭、联网搜索固定开启，不接受用户覆盖。图片通过 `user` 消息的 `image_url` 内容块传递实际像素，不再调用独立视觉模型或生成中间证据摘要。

语音固定使用阿里百炼北京 `qwen-audio-3.1-asr-flash` HTTP同步录音识别，转写进入 DeepSeek；原件保留60秒、3 MiB限制。SILK通过`silk-python`（模块`pysilk`）在可取消、资源受限子进程解码为16kHz、16bit单声道WAV，其他允许格式使用FFmpeg。临时音频不长期保存，不改变原件。

## 消息范围

自动回复处理文本、内置文字表情、语音及普通静态图片。所有 `MsgType=47` 贴图、动态图片以及 `MsgType=43/62` 视频均不下载、不解码、不进入 AI；排除覆盖唤醒、合并、拍一拍补充、引用及历史。纯视频静默，混合消息只处理允许内容。原始聊天、媒体定位和已有缓存继续保存，不重放历史任务。

拍一拍沿用原有触发和成员授权；群聊同成员近期素材、真实引用和历史读取不得扩大用户、微信身份或会话范围。

## 图片与恢复

管理台聊天记录只读展示自动回复已经准备好的静态PNG像素缓存，经认证、会话范围和SHA-256校验后返回；展示尺寸对应缓存图片，不承诺微信原始文件尺寸。没有缓存、缓存损坏或素材被排除时保留占位，不下载、重解码、重转写或修改素材处理状态。微信内置文字表情图标使用固定的官网资源归档，由本站随前端发布；这不扩大贴图或动态图片的AI准入范围。

语音记录采用横向声波气泡和秒数，保留已有转写。`GET /wechat/api/v1/accounts/{aid}/conversations/{cid}/history/{mid}/voice` 仅在点击播放后请求，经当前用户、账号、会话、消息可见性和原件 SHA-256 校验，从已有原件临时转换为浏览器可播放的 WAV；转写失败不影响原音播放。没有原件、校验或转换失败时不补取、不调用识别和模型、不修改任务或媒体状态。响应禁止缓存，临时副本随请求结束或取消回收；解码沿用受限子进程及30秒超时，生产共享媒体目录内两路内核文件锁限制所有 Web 进程，超量即返回繁忙，崩溃自动归还。页面打开、滚动、搜索均不请求音频。

用户确认清空会话后，关联原件、像素缓存、转写和媒体定位也永久清理。播放读取与清理通过共享媒体目录内固定64路读写锁互斥，清理完成前等待旧转换及其临时文件退出；转换返回前再次检查消息可见性，已清空语音不再返回。文件清理在数据库连接外执行，异常保留无正文的续清范围，完成前不报成功。不会因清空而重新下载媒体或调用模型。

保留原件、解码资源限制、静态判断、像素缓存与 SHA-256 校验。支持 JPEG、PNG、单帧 GIF 和单帧 WebP；图片不超过 32 MiB，解码沿用像素及单帧缓存限制。DeepSeek 请求体小于 48 MiB，沿用当前图片和真实引用优先的容量规则；超限或失败明确记录，不能用旧摘要冒充识图。

同一会话互斥，不同会话可并行准备；同账号按就绪顺序串行发送，两次发送完成至少间隔 1 秒。共享容量和累计预算持久化，外部等待不持有数据库事务。

新策略指纹阻止旧视觉分析及检查点恢复；已生成未发送的旧策略自动回复取消，未生成输入按新规则处理。发送中与未知结果只核对，不自动重试。数据库结构和历史业务数据保留。

AI模型设置内区分“智能回复 · DeepSeek”和“语音识别 · 阿里云百炼”，型号只读、密钥分别保存。`GET /settings`的`asr`返回固定provider、model、key_configured及脱敏key_preview，DeepSeek对应model_key_preview；只展示前7位、后4位，中间固定8个星号，长度不超过15位时全部遮挡，未配置时为空。脱敏在服务端完成，不返回完整密钥；前端以占位文字显示已保存片段，输入新密钥时仍以密码遮挡，不将占位文字作为值提交。`PATCH /settings`仅接受`asr_key`，不接受语音型号、参数或旧`media_key`。API Key按用户经Vault加密保存，运行时在当前用户范围内读取，无服务器环境密钥或历史密钥回退。留空保留原值，相同密钥重复提交不重复取消；保存只校验格式，不发起收费探测，“已保存”不表示模型调用已验证。变更仅取消本用户涉及语音的未发送任务，发送中和未知结果不重发。

固定参数`format=wav`、`sample_rate=16000`、`keep_dialect=true`、`speaker_diarization_enabled=false`，自动检测语种；不发送热词、聊天上下文或参照答案，不进行额外润色或金额、人名猜测。3.1模型自带文本规范化与原生润色，当前HTTP文档未明确提供关闭开关，不能宣称逐字一致。单次30秒、无自动重试，全用户跨进程共享两路容量，等待不占数据库连接。官方接口：https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api 。

语音缓存校验供应商、服务、型号和参数指纹；请求前持久记录尝试，取消、超时和崩溃结果不明时不自动重发。保留历史转写和原件，仅本轮需重新准备的素材使用新策略；不重放旧任务。供应商回执仅记录请求编号、错误码、音频时长与耗时，不记录音频、签名或凭据。

验收分别记录服务器隔离回归、真实模型结果、微信发送回执及手机实收。真实模型输入不记录 Base64、密钥或思考正文。
