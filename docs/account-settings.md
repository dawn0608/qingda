# 账户设置

账户弹窗为480px单页，窄屏自适应、短窗口仅正文滚动。顶部仅一个可点击头像；昵称输入与保存按钮同排，下方手机号和邮箱表单在原位置展开，每次只展开一处。验证码与获取按钮同排，联系方式确认按钮占满整行。

右上角关闭按钮悬浮时显示浅青绿底色和品牌文字色，按下时底色加深，沿用主题变量；禁用时不显示悬浮或按下反馈。

头像选择后独立保存，支持PNG、JPEG、WebP、GIF，上限5MiB。昵称、头像、联系方式分别提交；提交开始即同步禁止关闭、切换和重复提交。头像失败恢复最后确认的地址，昵称草稿不参与头像上传。

新头像先按EXIF方向校正并居中裁为正方形，使用LANCZOS缩放，最长保留1024px；小图不放大。JPEG以quality 95、无色度降采样保存，保留1600万像素的输入上限及现有认证、响应格式和版本地址。历史头像不重新编码。

联系方式只验证新目的地，仍须校验认证会话、CSRF、挑战用途、有效期及唯一归属。成功保留用户ID和业务归属；错误保留表单内容。资料反馈统一固定顶部短提示。认证规则见[验证码认证](authentication.md)。
