# 人工暂停与手动恢复

人工回复仍暂停当前会话 30 分钟，重复人工回复重新计时。智能助手回复范围的会话按钮展示实际状态；人工暂停不移除白名单，点击可提前恢复。账号总开关不因某个会话暂停而关闭，旁边展示全量人工暂停会话数。明确开启账号解除该账号所有人工暂停，保存提示词不解除暂停。

鉴权及 CSRF 保护的 `PATCH /conversations/{cid}/auto-reply`，请求为 `{"enabled": true|false}`，返回当前会话及 `server_time`。开启会话设置白名单并清除暂停；关闭移出白名单。操作在同一事务内更新 `ai_since`、`epoch`、取消未提交自动任务并记录审计。账号返回 `paused_conversation_count`、`next_pause_until`、`server_time`，统计不受会话列表上限影响。原白名单接口保持原语义。

前端只在服务端确认后展示开启；账号关闭、离线、关系异常等阻断保留说明。可见时每秒同步，恢复页面立即查询，暂停到期主动查询；操作前发出的旧状态响应被丢弃。恢复不补发旧消息，也不重发已提交平台的任务。

验收覆盖提前恢复、重复人工延时、自然到期、账号隔离、提示词保存及生成中恢复；仅恢复后新消息可触发回复。
